# 预测算法修复与验证：2026-09-06

已修复跨周校准污染、无条件保留最优候选、错误锁定和历史日期读取未来价格的问题。对尚未验证的极值暂停输出，参考区间不再用于购买成本上限。

## 实现

- [PricePredictionService.cs](../src/EndfieldPriceOverlay/Services/PricePredictionService.cs)：用完整周分别建立校准假设，为每个历史周保留各自的模板对应关系；不再把不同来源周的模板 ID 求交集，也不再以某一轮零残差替换已有 ε。相同价格周去重，重复周不额外计权。
- 历史周至少五个已知日期要在 3 个价格单位内匹配，才接受模板对应关系；最多两天的偏差保留在历史不确定范围中。按这些对应关系合并 ε，同模板已有实价用于校正，包括已观测到的极值。
- 当前周筛选采用固定的逐日拟合门槛，所有候选不合格时返回未匹配，允许撤销校准。3 单位容差覆盖当前八套模板之间整数取整的放大误差，不随最差拟合而放宽。`Confidence` 改为拟合分数，不再因存在一个完美匹配就把所有候选设为 1。
- [PredictionStatusService.cs](../src/EndfieldPriceOverlay/Services/PredictionStatusService.cs)：按查询日期隐藏未来价格；至少两个已知日期、未来价格分歧足够小且未超出支持范围，才输出收敛点预测。历史不确定范围过宽时保留参考区间；外推的新高、新低暂不输出，也不把历史最小/最大价猜成游戏硬上限。
- [PurchaseRecommendationService.cs](../src/EndfieldPriceOverlay/Services/PurchaseRecommendationService.cs)：只使用当日实价和收敛点预测；参考区间不进入优化，直接传入的区间报价也会被排除。缺乏必要未来价格时明确返回计划未就绪。
- 预测原理窗口同步说明新行为。原数据库不修改。

当前区间表达的是候选分歧、取整和已观察到的模型偏差，**不是已校准的概率区间或保证价格上限**。此前记录之外的规则变化，仍可能导致未来失配。

实际案例：

- 武侠电影货组以 7/22 截止：修复后预测 7/23～7/26 为 **1200、4295、1000、3502**，与实价一致；旧区间四天全部漏掉实价。
- 骨雕首次出现未验证低价时暂停对应未来输出；待该模板实价进入历史后，9/2 对 9/5 的预测恢复为 **630**，不再输出旧算法的 395。

这是针对已经分析过的同批历史进行修复验证，**不是独立的新周测试**。今后仍需用新采集周继续检验；这里的零大误差和区间覆盖率不构成未来保证。

## 测试和复现

完整测试 **97/97 通过**。新增 [校准回归测试](../tests/EndfieldPriceOverlay.Tests/PredictionCalibrationRegressionTests.cs) 和 [状态、购买回归测试](../tests/EndfieldPriceOverlay.Tests/PredictionReplayRegressionTests.cs)，覆盖：

- 512 种带整数取整的模板组合：重复中间周前后曲线及范围不变；存活曲线的未来误差均不超过 3，范围包含实际值。
- 历史顺序调整、前导不完整周、完全失配和置信度区分。
- 历史日期隔离、周一不锁定、未记录与失配提示分开。
- 未验证极值暂缓、同模板极值再次出现时恢复实价。
- 错误当前记录撤销预测，参考区间不能进入购买计划。

原测试中依赖旧错误区间的断言已更新。购买建议的“其他物资今日实价参与”用例修正了与其校准序列不一致的 1313 读数为 1216；错误读数另由撤销预测测试覆盖。
